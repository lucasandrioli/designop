# Receitas comuns

Este arquivo recebe apenas padroes observados em duas ou mais telas
humanas reais. Nao e uma fonte de regra de negocio nem uma lista de
componentes inventados.

## Padroes confirmados

Nenhum ainda.

## Como registrar

Para cada padrao, informe:

- o que se repete na construcao;
- telas humanas em que foi observado;
- data da ultima observacao;
- confianca: MEDIA ou ALTA.

Com uma unica tela, o padrao permanece na receita especifica com
confianca BAIXA. O Aprendiz nao promove hipotese para este arquivo.
